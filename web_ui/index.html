ECM Workspace

Documents without the scaffolding.

One screen to describe a document type, create a document, and find it again. The API is behind the page, not in front of you.

1. Connect

Use the same server for both the API and the interface. No separate front-end process is required.

2. Document Type

Create the shape of a document once, then reuse it for every record.

3. Document

Choose a type, fill the business fields, add the content, and save.

Last document: none

4. Find

Search by title, content, or metadata. If you know the type field, use `metadata:field`.
